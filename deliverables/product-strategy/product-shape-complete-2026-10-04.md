## 1. 理念：这台机器到底在替你干什么

### 1.1 一句话

> **你不是在挑金狗，你是在把不值得看的全部划掉。划得越准，剩下的越少，剩下的才越值钱。**

### 1.2 为什么是这个理念

市场上所有工具（GMGN / DexScreener / BullX / Axiom）都在做同一件事：**给你更多**。更多新池、更多榜单、更多信号、更多钱包。因为它们靠 1% 成交费活着——你下单越多它们越赚。所以它们的信息架构天然是"当下快照 + 排行榜 + 一键下单"。

这个产品反着来。它是**单机自用、零订阅、不接交易**的，所以它唯一该优化的是：**把你有限的注意力，从 800 个候选压到 ≤5 个，并且让你敢信这个压缩**。

这就要求三件事同时成立，缺一个这台机器就是废铁：

| 支柱 | 含义 | 缺了会怎样 |
|------|------|-----------|
| **① 给结论不给列表** | 打开就回答"今天该看哪几个" | 你还是得自己扫 38 张卡，等于没做产品 |
| **② 证据链可解释且诚实** | 每个结论挂一条你能自己核的数字，拿不到就说拿不到 | 变成另一个"看起来很专业但没法验证"的玩具 |
| **③ 能自证发现力** | 记录"我当时划掉/留下了什么，后来怎样了" | 工具会自嗨，你永远不知道它到底行不行 |

**第 ③ 条当前是 0**（`outcomes` 长度为 0，feed 行 0.98 小时就被删）。这是理念层面最严重的问题——不是功能缺失，是**这台机器现在无法被证伪**。所以路线图把"装仪表"排在最前面。

### 1.3 它明确不是什么

不是行情终端、不是交易平台、不是"另一个 GMGN"、不是社区、不是榜单、不做多链扩张、不接一键下单、不托管任何私钥。**做大了就是做砸了。**

## 2. 用户视角：三个真实场景，形态怎么回应

> 来源：瑞思（用户研究员）`.workbuddy/tmp/ps-ux-user-view.md`

### 场景 A · 早上开机第一眼

**他脑子里的问题**：「今天有没有值得我看的东西？如果有，是哪几个？」

| 环节 | 他的状态 | 形态回应 |
|------|---------|---------|
| 打开 | 不想被 38 张卡淹没，只想先知道"有没有" | **结论层 C1 在首屏最顶**，3 秒内可答，不需滚动 |
| 判断值不值得细看 | 需要一句话的理由，而不是一串标签 | 每条结论挂**一句可核对的理由**（含数字 + `basis=来源@时刻`） |
| 决定看哪个 | 要点一下就到，不要新开面板 | 点击 → **滚动并高亮到同一网格里那张卡**（不是弹窗，不违反一个网格） |
| 什么都没有时 | 也该是一屏完整答案，不是空白 | 空态给出：本轮进了多少/划掉多少/下一次扫描时刻/基线对比 |

### 场景 B · 盘中刷出一个新信号

**他脑子里的问题**：「这是不是真的、我能不能自己核、现在还来不来得及？」

| 环节 | 痛点（真实原话） | 形态回应 |
|------|----------------|---------|
| 看数值 | 「市值 未知 → 未知 这样显示很难看」 | **未知三态组件 C4**：未取到 / 未检测 / 未评估，冷灰墨 + 虚线下划线 + `?`，且必须跟一句「不参与 X 判定」；**两侧都缺则整行不印**，绝不出现 `X → —` |
| 判断真假 | 怕被假安全骗 | 安全区改**逐项明细 + basis**，**不给总分**；BSC 的 rug 恒「未评估 ?」 |
| 核数据 | 凭什么信这个倍数 | 每个数字带 `basis=来源路由@时刻`；倍数自曝口径（如 `basis=marketCap（非价格）`） |
| 知不知道来不来得及 | 需要时间感 | 首见时刻 + "首见起 Xm" + 数据年龄角标（降级时变红） |

### 场景 C · 复盘 / 被打脸

**他脑子里的问题**：「我上次为什么划掉它？我划对了吗？」

🔴 **主理人裁决（分歧 D1）**：瑞思主张复盘是"唯一的证伪回路"、不是"大盘子"。**我支持瑞思，并且实测发现它根本不是新功能**——
`public/index.html:1313-1319` 已有「筛选后表现验证 / 30分钟结果 / 2小时结果」，`src/server.mjs:906/1462` 已接线（`outcomeSummary` + `outcomes.slice(0,1000)`）。
它之所以永远空着，是因为 `src/outcomes.mjs:31` 写着 `provider !== 'AVE' → return []`，加上 `FEED_LEAD_RETENTION_MS = 60min`。
→ **所以复盘表的最小形态 = 修复已有接线 + 窗口抬到 T+24h + 保留期抬到 ≥24h，工作量 S，不是新建大盘子。**

## 3. 六条设计原则（含每条的代价）

| # | 原则 | 主张 | 落地的 UI 决定 | **牺牲了什么** |
|---|------|------|---------------|--------------|
| 1 | **结论先行且可指** | 首屏 ≤5 个 + 一句能在这张卡上指到的数字 | 结论层是**同一网格的置顶指针**，点击滚到卡；不复制数据、不开面板 | 牺牲排序的可解释性（不是"排序第一"而是"它值得看"） |
| 2 | **划掉是主业、必须可见** | 被划掉的必须看得见、数得清、查得到原因 | 报数行四项成对全印 + 「上一轮清掉了什么」独立一行 + 今日淘汰清单（同网格第 4 分段） | 牺牲首屏纯净度 |
| 3 | **未知有专门的脸** | 未知绝不能长得像"安全/通过" | 三态缺口固定长相（冷灰墨 + 虚线 + `?`），禁止 0 / false / ✓ / 空白 | 牺牲卡面饱满度（BSC 卡可能 9 项里 4 项未评估） |
| 4 | **可核对 = 双时点 + basis** | 每个数字两个时刻 + 来源 | 变化轴 `旧 → 新 ×N.NN` + `basis=路由@时刻`；**不给总分** | 永久牺牲跨源交叉验证（单源后消失） |
| 5 | **一个网格、一张卡** | 同地址恰好一张卡 | 结论层是指针；页脚是源健康/战绩/复盘，**不是币网格** | 牺牲对比视图、抽屉、第二视图 |
| 6 | **默认即正确，不给旋钮** | 不让他伺候工具 | 只保留导航型控件（排序/链切换/折叠）；**行动区止于复制地址** | 牺牲可玩性与即时性（不能"调参试试"） |

### 5.2 未知的三张脸（本轮最重要的视觉发明）

| 态 | 含义 | 视觉编码 | 必须附带的话 |
|----|------|---------|-------------|
| **未取到** | 这次没拿到，可能回来 | 冷灰墨 + 虚线下划线 + `?` | 「不参与该项判定」 |
| **未检测** | 这条路由根本不提供 | 同上 + tooltip 说明 | 「此链/此路由不提供」 |
| **未评估** | 拿到了但值是假的（BSC rug 恒 0） | 同上 | **「此链该字段恒 0，不作答」** |

**禁止**：`0` / `false` / `✓` / 空白 / `—` / `--` / `N/A` / `未知 → 未知`。

### 5.3 排版与栅格

- 字号下限 **14px**（项目 `test/ui.test.mjs` 硬断言）；禁 `em`、禁改根字号
- 数字统一：等宽、右对齐、金额 `$N.NK`、倍数 `×N.NN`、比率 `0.NN`、时间 `HH:MM`
- 栅格：1280 / 1440 / 1920 **都是 3 列**；1920 多出的空间用于「少折叠一次」，**不是多塞卡**
- 动效：只允许数据更新的过渡；**禁止装饰性动画、闪烁、emoji、渐变徽章、星级、插画**

### 9.4 12 条验收句（打开原型，30 秒逐条判）

1. 打开 3 秒内说出「今天有没有东西要看」，**不需要滚动**。
2. 结论层最多 5 行；>5 时明说「还有 m 个在下面」，不是静默截断。
3. 结论层理由里的数字，能在同一张卡上指到一模一样的那个。
4. 卡面找不到任何裸的「未知 → 未知」/「—」/「--」/「N/A」。
5. 任一列遮住标签也能比出 5 个值的大小。
6. BSC 卡上不出现「安全 / 通过 / ✓ / 已评估」，rug 行恒「未评估」。
7. 10 秒内能说出「上一轮清掉了几个、分别因为什么」。
8. 断网/停摆时顶部横幅同时有停止时刻 + 原因 +「这是历史快照」。
9. 每张卡看得出数据多老，降级时卡片肉眼可辨地变灰。
10. 灰度化后仍能第一眼看出哪一行是坏消息。
11. 首屏找不到任何一个「删掉也不损失信息」的元素。
12. 页面从不问我问题，异常时它自己说清原因与恢复时间。
